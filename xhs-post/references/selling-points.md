### 🔑 防护要从桩体转到枪头讲

**桩体 IP 值不是雷*恩最强的地方，枪头才是。**

| | 桩体 | 枪头 |
|---|---|---|
| 雷*恩全系 | IP65 | **IP67** |
| `*达`开拓者 | IP66（高于我们） | IP55 |
| `*牛`三款 | IP55 | IP54 |
| `*米` | IP55 | IP55 |
| `*想` | IP55 | IP55 |

只比桩体，`*达`开拓者 IP66 高我们一档，论点会被读者反驳。**转到枪头，差距是 IP67 vs IP55，两个量级。**

而且枪头才是真正暴露的部件——插拔在手上、平时挂着、雨水顺着线往下淌。桩体固定在墙上还有遮挡，枪头没有。**这个论证既诚实又更有说服力。**

标准写法：
> `*达`开拓者桩体 IP66，比磐石Pro 的 IP65 还高一档。但它枪头是 IP55，磐石Pro 是 IP67——露天的话，天天插拔的枪头比挂在墙上的桩体更要紧。

## 卖点 → voice 的搭配

不是任意组合都成立：

| 卖点 | 天然搭配 | 别用 |
|---|---|---|
| 耐候防护 / 老小区适配 | `first-person-journey` `head-to-head` — 场景型卖点需要真实经历托底 | `hardcore-review`（讲不出场景） |

## 参数要落到「跟我有什么关系」

这是 v1 的写作要求，卖点表达的核心：

|---|---|

## 竞品的真实优势（必须如实列出）

合规红线要求不藏竞品优点。**读者查得到，藏了反而伤信任。** 常用的诚实对照：

| 竞品 | 客观强于磐石Pro 之处 |
|---|---|
| `*达`开拓者 | 桩体 IP66（高于 IP65）；质保 6 年（长于 2+2）。**但枪头仅 IP55，见上方「防护要从桩体转到枪头讲」** |
| `*牛`乐享 | 自带智能数显屏；5 年维修质保 |
| `*米` | 生态联动、一键开盖；8 年免费流量 |
| `*想` / `特*拉` | 原厂车机一致性、一键开盖 |

**雷*恩靠自己的强项立住，不靠贬低。** 写法：先诚实列出对方的强项和适合谁，再说雷*恩适合谁——对号入座，不下"谁最好"的结论。

**品牌定位已更新：雷*恩在第三方充电桩中综合 Top3–Top5，销量稳定在榜。** 早期"新锐小厂"的保守策略已不适用。

| 项 | 说明 |
|---|---|
| 数据支点 | 电商平台销量榜位次（需有截图佐证） |
| 对谁说 | 决策疲劳、不想研究参数、认"大家都买"的人 |
| 行文逻辑 | 榜单位次 → 为什么它能上榜（回到硬参数）→ 对号入座 |
| 配图形式 | `screenshot` 平台榜单截图 |
| 天然搭配 | `persona-match-review` `nanny-guide` |

### ⚠️ 可打什么、不可打什么

| ✅ 可以 | ❌ 不可以 |
|---|---|
| 用**平台原生标签的截图**（如"霸榜前三 3 周"、"近30天销量300+"） | 在正文里写"销量第一""销量冠军"——仍属极限词 |
| 陈述**可截图佐证的具体位次**（第三方 Top3/Top5） | 写"全网销量领先"这类无来源的模糊断言 |
| "跟着销量榜买"这类引导（现在对我们有利） | 编造具体销量数字、市占率、网点数量 |

**首选做法：用截图，不用文字断言。** 平台自己打的标签是平台的话，写进正文就成了我们的话，举证责任不同。

**已定（2026-08-18）：本卖点只走"用截图"这一档，不写进正文。** 相关截图由验收人员自行处理，模型不需要也不应该在正文里陈述位次——写进正文容易违规。
