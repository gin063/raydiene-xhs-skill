# 卖点库

**主打卖点是 PLAN 阶段的独立决策，和 voice / art 同级。** 打哪个卖点会反过来决定行文逻辑和配图形式——先定卖点，再定怎么写。

所有数值以 `3C充电桩对比产品信息-更新至260731.xlsx` 为准，本文只给对照关系，**不作为参数来源**。

## 卖点 → voice 的搭配

不是任意组合都成立：

| 卖点 | 天然搭配 | 别用 |
|---|---|---|
| 耐候防护 / 老小区适配 | `first-person-journey` `head-to-head` — 场景型卖点需要真实经历托底 | `hardcore-review`（讲不出场景） |
| 安全冗余 | `hardcore-review` `first-principles` — 要下钻到元器件才立得住 | `meme-remix`（信息密度不够） |
| 性价比 | `head-to-head` `persona-match-review` — 需要对照物 | 单品帖（没有对照，"便宜"是空话） |
| 无隐性支出 / 售后确定性 | `nanny-guide` `structured-guide` — 清单型卖点 | — |
| 功能齐全 | `first-person-journey` — 功能要落到动线才有感 | `structured-guide`（会变成功能罗列） |

⚑ 这张表是我从卖点性质推的，没有转化数据验证。**PLAN 阶段应把卖点选择理由写进 `axes.rationale`，等转化数据回流后反查。**

## 参数要落到「跟我有什么关系」

这是 v1 的写作要求，卖点表达的核心：

| ❌ 罗列 | ✅ 关联 |
|---|---|
| 枪头 IP67 | IP54 只能挡溅水，IP67 能短时浸泡——露天车位一场暴雨就见分晓 |
| 介质耐压 5000V | 国标要求 1500V，这个值是余量，雷雨天电网波动时是它在兜底 |
| 终生免费流量 | 别家 4 年后要续费，一年几十块，五年下来就是小两百 |
| 支持调节电流 | 老小区进线细，满功率容易跳闸，调低一档整晚照样充满 |

## 竞品的真实优势（必须如实列出）

合规红线要求不藏竞品优点。**读者查得到，藏了反而伤信任。** 常用的诚实对照：

| 竞品 | 客观强于磐石Pro 之处 |
|---|---|
| `*达`开拓者 | 桩体 IP66（高于 IP65）；质保 6 年（长于 2+2） |
| `*牛`乐享 | 自带智能数显屏；5 年维修质保 |
| `*米` | 生态联动、一键开盖；8 年免费流量 |
| `*想` / `*斯拉` | 原厂车机一致性、一键开盖 |

**雷*恩靠自己的强项立住，不靠贬低。** 写法：先诚实列出对方的强项和适合谁，再说雷*恩适合谁——对号入座，不下"谁最好"的结论。

## 不能打的卖点

- **品牌力 / 销量 / 榜单** — 雷*恩是新锐小厂，"跟着销量榜买、避开小众品牌"对我们是反向操作。判断权要引到"3C 编号能不能查到"，那是我们的主场
- **内存 / IO 接口** — 属降配项，见 `compliance.md` 第 4 节，信息图和产品卡里直接不提
- **认证起草 / 行业地位** — 不编造，雷*恩非国标或认证起草单位
