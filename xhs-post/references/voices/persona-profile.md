# persona-profile 人物画像避坑体

> ⚠️ **本规格无样本、无 tier 验证。** 36 篇语料里没有这个类型，规格来自 v1 实操经验（「避坑/人物画像」体裁）+ 相邻 voice 推导。**整份文件的置信度低于其他 voice**，跑过几篇后按实际效果修订。
>
> 标记约定：无标记 = 可在样本或 v1 经验里找到依据；**⚑** = 推断。

## 核心

**对号入座的对象是「人的行为错误」，不是产品。**

这是它和 `persona-match-review` 的根本区别，也是最容易混的地方：

| | persona-match-review | persona-profile |
|---|---|---|
| 对号入座的对象 | 产品（哪款适合你） | 人（你是哪种错法） |
| 读者的动作 | 挑一个 | 认领一个 |
| 情绪 | 中立筛选 | 被说中的刺痛 + 庆幸 |
| 结尾 | 各得其所 | 别当这几种人 |

读者读它是为了**确认自己不是那种人**，或者**发现自己正是那种人**。两种反应都会让他继续读下去——前者获得优越感，后者获得危机感。

## 骨架

```
1. 冲突式开场       —— 抛出"有人花冤枉钱"这个事实
2. 立规矩           —— 说清楚为什么这几类人吃亏（共同的认知错误）
3. 逐类画像 ×N      —— 每类 = 画像一句 + 硬知识点一条
4. 反转收束         —— "其实不难，看三个东西就够了"
5. 产品落地         —— 按 placement 强度决定给到什么程度
6. 引导评论         —— "你中了几条"
```

**每类人 = 画像一句 + 硬知识点一条。** 这是本体的最小单元，两者缺一：
- 只有画像 → 变成嘲讽，读者反感
- 只有知识点 → 变成 `structured-guide`，失去代入感

⚑ 建议 4–6 类。少于 4 撑不起"几类人"的承诺，多于 6 读者记不住。

## 排序

**按真实时间线排，不按严重程度排。** 装桩的决策顺序是：要不要装 → 办电表 → 选桩 → 装 → 用。画像也按这个顺序走，读者能跟着自己的进度对号。

⚑ 按严重程度排会让前几条太重，读者一开始就被劝退。

## 语言特征

**略带调侃，但不骂读者。** 这是本体最难的平衡：

| ✅ 骂行为 | ❌ 骂人 |
|---|---|
| "这钱花得最冤" | "这种人最傻" |
| "第一次装桩最容易栽在这" | "小白就是不懂" |
| "我当初也是这么想的" | "别学他" |

⚑ 最稳的做法是**把自己算进去**——"这条我当年中过"，把嘲讽转成同类相怜。样本 019「骂醒一个算一个」的 🤡 自嘲开场就是这个机制，只是它用在了 `nanny-guide` 上。

**标题可以狠，正文必须收。** 标题里的"最傻""花钱买罪受"是钩子，正文第一段就要软下来，否则读者被冒犯就走了。

## 长度与承载度

⚑ 推荐 `image-led`：正文 350–500 字，**每类人一张图**，正文只留开场、规矩、收束和产品。

理由：画像 + 知识点这个结构天生适合卡片化，一类人一张卡，读者可以只截自己中的那张转发。挤在正文里会变成一长串，失去"认领"的仪式感。

## 配图

- 每类人一张卡：`memo-text` 或 `note-app-screenshot`，`ugc-raw`
- 封面：数字承诺型（"6 类人" 大字）或对号入座网格
- ⚑ 每张卡建议统一版式：顶部画像标签（如「只认原厂的人」）+ 中部一句现象 + 底部知识点

## 植入

⚑ **建议 `medium`，慎用 `hard`。**

本体的逻辑是"我在帮你省钱"。指出一堆错误之后立刻推销，会变成"骂完你然后卖你东西"，吃相难看，且和"我在帮你"的立场自相矛盾。

`medium` 的做法：在收束段给判断标准（看 3C、看防护、看流量年限），产品作为符合标准的例子之一出现，不做排他推荐。

## 反例

❌ 每类人后面直接跟产品推荐 —— 变成六次广告
❌ 画像太具体到可对号入座某个真人 —— 平台会判定人身攻击
❌ 用"你"做主语骂 —— 换成"这类人"或"我当初"
❌ 六类人的知识点互相重复 —— 每类必须对应一个不同的知识点，否则读者读到第三类就走
❌ 标题狠、正文也狠 —— 钩子和内容都在攻击，读者没有喘息处

## 复写要点

⚑ 可组合矩阵：**决策阶段（要不要装/办电表/选桩/安装/使用）× 错误类型（认牌子/贪便宜/贪功能/图省事/不问清楚）**。

复写时换画像的具体表述和挂载的知识点，保留「画像一句 + 知识点一条」这个最小单元和时间线排序。
