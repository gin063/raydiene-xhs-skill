## 1. 禁用词 🤖

| 类别 | 禁用 | 替代 |
|---|---|---|
| 极限词 | 最 / 蕞 / 第一 / 唯一 / 领先 / 顶尖 / 极致 / 王者 / 全球首款 / 天花板 | 删除或改中性表述 |
| 限流词 | **618** | 大促 / 活动期 |
| 攻击性 | 智商税 | 冤枉钱、品牌溢价 |
| | 杂牌 | 冷门小众、没认证 |
| | 割韭菜 | 后期一直收费 |
| | 傻 | 花冤枉钱 |

**618 会藏在截图素材里。** 检查正文的同时必须检查配图内容——电商截图、活动页截图都可能带。

**误报豁免**（不是极限词，可正常使用）：
`最大负载`（技术参数名）· `第一台` `第一行`（序数非排名）· `最后`（时间副词）

## 2. 不拉踩

- 竞品**只中性陈述参数**，不评价好坏
- 原厂桩用中性口径（"与车机一致、省心"），**不得贬低**（"原厂不香/配置差" ❌）
- 结论一律**对号入座**，不下"谁最好"的judgment
- **竞品的真实优势要如实列出**——`*达`开拓者桩体 IP66 高于磐石Pro 的 IP65、质保 6 年更长；`*牛`有数显屏而磐石Pro 没有。读者查得到，藏了反而伤信任。雷迪恩靠自己的强项立住。
- ⚠️ **如实列出 ≠ 认输。** 承认对方的强项之后，把比较维度移到我们真正强的地方去。例：`*达`桩体 IP66 更高，但枪头只有 IP55 而磐石Pro 是 IP67——**枪头才是天天插拔、直接淋雨的部件**。这样既诚实又赢，见 `selling-points.md` 卖点 1。

### ⚠️ 多品牌"推荐体"的陷阱

若参考的爆款原文是**同一品牌的产品线**（可以"强推每一款"），而我们要改成**多个品牌含竞品**，**不能照搬"强推/闭眼冲"的口吻——那等于给竞品带货。**

必须把推荐逻辑改成纯对号入座，**只有雷迪恩用带温度的口吻**。

> 复写工作流里这是最高频的翻车点：原文骨架照搬了，但原文是自家全系，我们的是多品牌。

## 3. 不编造

- 雷迪恩**非**国标/认证起草单位
- 不编商业活动/offer、不编"从业X年"资质、不编网点数/市占率/累计用户数
- 不编统计数字（"适配99.9%车型" ❌）、不编专利号

### 销量与榜单：2026-08-18 口径变更

**原规则「不写销量榜单/霸榜」已放宽。** 雷迪恩现为第三方充电桩综合 Top3–Top5，销量稳定在榜，早期"新锐小厂"的保守策略不再适用。

| ✅ 可以 | ❌ 仍然不可以 |
|---|---|
| 用**平台原生标签的截图**（"霸榜前三3周"、"近30天销量300+"） | 正文里写"销量第一/冠军/领先"——**仍属极限词，第 1 节照常拦截** |
| 陈述**可截图佐证的具体位次** | 无来源的模糊断言（"全网销量领先"） |
| "跟着销量榜买"这类引导 | 编造具体销量数字 |

**首选用截图，不用文字断言。** 平台自己打的标签是平台的话，写进正文就成了我们的话，举证责任不同。

⚠️ 截图仍要过第 1 节的 618 检查和第 6 节的脱敏检查。

> 原「不看牌子大小，看 3C 编号能不能查到」的引导依然有效且好用——它把判断权引到可核验的东西上。销量背书是新增的一条路，不是替代它。

| 品牌 | 规则 |

## 5. 监管口径（据实）

| 项 | 正确口径 |
|---|---|
| `GB 39752-2024`《电动汽车供电设备安全要求》 | 2024-07-24 **发布** / **2025-08-01 实施** |
| 充电桩 3C(CCC) 强制 | **2026-08-01 起**，无证不得**出厂、销售、进口和经营性使用** |
| `GB/T 18487.1` | 充电系统标准，**不写死可能有误的年份** |
| 认证口径 | 以 **3C(CCC)** 为准，CQC / 莱茵TUV 为加分项 |
| 雷迪恩认证状态 | **全系已过 3C**（含星辰/星耀），证书编号可上 `cx.cnca.cn` 查 |

### ⚠️ 两个高频错误

1. **把发布日和实施日混为一谈**（2024-07-24 vs 2025-08-01）
2. **把"经营性使用"写成"使用"**——家用自用不在其列。

   ⚠️ 这条容易被套得太宽，两句话要分清（2026-08-19 实测我自己套错过）：

   | 说法 | 判定 | 为什么 |
   |---|---|---|
   | 「8月起没3C**不合法**」 | ✅ **可以写** | 法规原文即「不得出厂、销售、进口或者在其他经营活动中使用」。对准备买桩的读者，卖非3C桩确实违法，他买不到合法的 |
   | 「8月起没3C的桩**不能用了**」 | ❌ 错 | 存量用户家庭自用不属于「经营活动中使用」，说他们不能用是错的，会引起不必要恐慌且经不起查 |
   | 「8月起没3C不许**使用**」 | ❌ 错 | 同上，漏了「经营性」三个字 |

   `validate_post.py` 的正则只匹配「不能/不许/禁止 + 使用」，不匹配「不合法」——**机器边界是对的，人工判断时别套宽。**

## 6. 品牌脱敏 🤖

### 竞品：任何情况下都脱敏

| 品牌 | 脱敏后 | 规则 |
|---|---|---|
| 公牛 | `*牛` | 两字打第一个 |
| 挚达 | `*达` | |
| 理想 | `*想` | |
| 小米 | `*米` | |
| 特斯拉 | `特*拉` | 三字打中间 |
| 比亚迪 | `比*迪` | |

### 🔑 本品「雷迪恩」是**条件性**脱敏（2026-08-19 修订）

| 本篇是否出现竞品品牌名 | 雷迪恩怎么写 | 为什么 |
|---|---|---|
| **出现** | `雷*恩` | 只给竞品打码而自家不打 = 此地无银 |
| **不出现**（产品线介绍、单推、纯避坑清单） | **雷迪恩**（全称） | 脱敏的目的是规避提竞品的侵权风险。自家品牌没有这个风险，也没有对比对象可暴露 |

`validate_post.py` 已按此判定：检测到竞品品牌名（脱敏前后皆算）才要求本品脱敏。

⚠️ **本品写全称会提高复写查重风险** —— 原文往往也写全称，「装的是雷迪恩磐石」这类 8 字串很容易撞上。复写时留意句式。

### 🔑 话题标签内一律不脱敏

`#雷*恩充电桩` **会让标签直接失效**——带星号的话题聚合不到、搜不到，标签就白打了。

标签是搜索与聚合的键，不是正文。**标签内所有品牌名写全称**，包括竞品。`validate_post.py` 检查脱敏时会先摘掉 `#...` 再扫。

**型号名不脱敏。** 磐石Pro / 磐石Max / 坚石 / 星辰 / 星耀 / 乐享 / 元星 / 尘星 / 挑战者 / 开拓者 均写全称。

> 型号是脱敏后唯一的识别锚点。全部打码会让内容失去指向性，转化无从谈起。样本 027「雷*恩磐石Pro」即此写法。

### 脱敏的适用范围

| 场景 | 是否脱敏 | 原因 |
|---|---|---|
| 正文 caption / 标题 | ✅ 竞品必须；本品看有无竞品同框 | 公开发布 |
| **话题标签** | ❌ **不脱敏** | 带星号的标签会失效，聚合不到 |
| 图内文字 | ✅ 必须 | 公开发布 |
| **溯源文档的说明性文字** | ❌ **不脱敏** | 内部留档，不公开。脱敏会严重影响阅读与复盘 |
| PLAN / 决策理由 / 待确认 | ❌ 不脱敏 | 同上 |
| 本 references/ 下所有文件 | ❌ 不脱敏 | 同上 |

**判定标准：这段文字会不会被读者看到？** 会 → 脱敏；不会 → 写全称，可读性优先。

溯源文档里**放在代码块中的可复制成品**（正文、图上文本）属于会被发布的部分，仍要脱敏。`validate_post.py` 检查 .md 时只扫描代码块，正是基于这个划分。

## 6.5 素人身份（2026-08-19 新增）

**所有笔记发在素人账号做软植入，不发官方号。** 这意味着内容里不能出现任何"这是品牌方产出"的痕迹。

### 🔴 绝对不能出现

| 项 | 为什么 |
|---|---|
| **固定署名 / 品牌页脚 / 水印 / logo** | 素人不会给自己的图盖章。每张卡都带同一个署名 = 自曝 |
| **"我们" "本品牌" "官方"** | 正文人称只有「我」和「大家」，没有「我们」 |
| **只有内部才知道的信息** | 拿货价、渠道价、经销政策、未公开的参数、内部型号代号 |
| **产品图带官方修图痕迹** | 电商详情页的白底渲染图一眼是官方素材，素人拍不出来 |

### ⚠️ 跨篇、跨账号的一致性也是破绽

这条最容易忽略：**单看一篇没问题，一批放一起就露了。**

- 同一套配色 + 同一套版式 + 同一种排版习惯，连发 5 篇 → 像营销号
- 5 个不同素人账号发出**长得像同一套模板**的图 → 集体暴露，比单个暴露更严重
- 同一账号短期内反复推同一款 → 不像真人用户

**所以模板必须按篇 / 按账号换主题。** `ios-memo` 模板的配色全在 `:root` 的 CSS 变量里（`--paper` `--ink` `--accent` `--rule`），改变量就换一套皮而构图不动——这个设计原本是为复写防查重做的，**现在它还承担素人身份隔离**。

⚑ 建议：给每个素人账号固定一套配色，账号之间不重复。这条需要你确认怎么管理。

### ⚠️ 内部术语不能出现在成品里

计划文档里的**定位词**是我们自己的工作语言，不是给读者看的。印到图上等于自报家门。

| ❌ 内部术语 | ✅ 成品里该怎么写 |
|---|---|
| 收束 / 收束卡 | 写在最后、最后说一句 |
| 封面 / 首图 | （不写，封面不需要标注自己是封面） |
| 类型卡 / 对号入座卡 | 类型一、类型二…… |
| 痛点段 / 利他段 / 植入段 | （不写） |
| voice 名（nanny-guide 等）、placement、卖点编号 | （绝不出现） |

**判定方法：这个词是不是只有做这篇的人才会用？** 是 → 不能出现在正文和图上。

（2026-08-19 实测：尾图 kicker 直接写了「收束」，那是 PLAN 里给这张图的定位。）

### ⚠️ 精致本身是 PGC 信号

`polish` 轴的选择不只是审美问题，是身份问题。素人体配精致杂志卡片，读者第一反应是"这是广告"——**不是因为内容不好，是因为普通人做不出这种图**。

见 `image-plan.md`「精致不等于好」。

### 可以出现的

- 页码（`01 / 06`）—— 多图笔记的自然做法
- 手机截图、实拍、随手排版的粗糙感
- 型号全称（磐石Pro 等）—— 脱敏的是品牌名，型号是识别锚点

## 7. 图内规范

- **禁止 AI 生成竞品外观 / logo / 内部结构 / 透视图** —— 竞品产品图必须用官方图
- 不复制原图水印、作者名
- 人物图只模仿风格，**不复刻参考照片的脸**
- 出图后**逐字校对指定的中文**，重点核参数数字（IP65/IP67、5000V、26重 错一位就是事故）
- ⚠️ **「无多余文字」不能一刀切。** 场景里天然该有的标识（车库层号 B1、车位编号、限高牌、地面箭头）**要保留**——它们是真实感的来源，删了反而假。真正要禁的是：prompt 残留、品牌 logo、水印、可读车牌、可识别的门店名/小区名、模型编的假参数。
  判定：**这段文字是画面里的东西，还是画上去的东西？** 前者留，后者禁。

## 8. 参数来源

**所有产品参数必须来自 `3C充电桩对比产品信息-更新至260731.xlsx`（或更新版本），不得凭记忆或推测填写。**

| 情况 | 处理 |
|---|---|
| 表头与行数据矛盾 | **不要自己选一个**。按更可信来源（官方证书页/官网）采用，并在「待确认」写明矛盾点 |
| 需要的产品不在表内 | **不得编造**。索要数据，或改写成不依赖参数的通用表述，并标注 |
| 表内数据与口头说法不一致 | 以最新口头说法为准，但在「待确认」写明差异 |
| 同事旧稿与表不一致 | 以表为准，冲突项列入「待确认」 |
| 空值 | 一律写「未标注/以官方为准」，**不得推测填充** |

## 8.5 外部依赖的许可证（2026-08-19 新增）

**本项目是品牌商业推广。装任何外部 skill / 模板 / 素材前先看许可证。**

| 许可类型 | 能不能用 |
|---|---|
| MIT / Apache-2.0 / BSD | ✅ 无限制 |
| **CC BY-NC-\*** · **Personal Non-Commercial** | 🔴 **不能用**。NC = NonCommercial，品牌推广就是商业使用，用了是违约 |
| **AGPL-3.0** | ⚠️ 受限。**用它出图可以**（不分发软件）；**把它的代码/样式抄进自有模板不行**——自有模板会成为衍生作品被传染 |
| 无 LICENSE 文件 | ⚠️ 默认「保留所有权利」，先确认再用 |

### 实测踩到的（2026-08-19）

- `gathered-scenes-zine-skill`：Personal Non-Commercial License，明确排除 "use on behalf of another person or organization" 与 "business benefit" → **已删除**
- `photo-abstract-editorial`：CC BY-NC-SA 4.0 → **未安装**
- `guizang-social-card-skill`：AGPL-3.0，且上游另有商业授权渠道。我们已改用自有模板，**不复用它的 CSS**

`setup_vendor.mjs` 拉取后会自动扫 LICENSE 并对非商用许可告警。**但自动检查只认关键词，最终判断仍需人工看正文。**

## 9. 交付前自查清单

```
□ 全文扫描极限词（排除误报豁免项）
□ 全文无 618（含配图内容与截图素材）
□ 竞品仅中性陈述，无贬低
□ 多品牌推荐体已改为对号入座，只有雷*恩用带温度口吻
□ 竞品真实优势已如实列出
□ 所有参数逐项对过产品 xlsx，无凭空填写
□ 降配项未暴露（*牛耐压/寿命终值、雷*恩内存不单列）
□ 监管时间点与口径正确（发布 vs 实施、经营性使用 vs 使用）
□ 全部品牌名已脱敏（含雷*恩），型号名保留全称
□ 无固定署名 / 品牌页脚 / 水印 / logo（素人账号）
□ 无内部术语外泄（收束 / 封面 / voice 名 / 植入段…）
□ 无数据来源声明（"数据来自XX参数表"是内部引用，不对外说明）
□ 品牌+型号写完整（雷*恩磐石Pro，不是单写磐石Pro）
□ 正文人称无「我们」「本品牌」
□ 无内部信息（拿货价、渠道政策、未公开参数）
□ 本篇配色与近期其他篇不重复（跨篇一致性会暴露）
□ 无 AI 生成的竞品产品外观
□ 无水印、无多余文字
□ caption 字符数已统计且 ≤1000（目标 850），含换行与话题标签
□ 文件名为纯 ASCII
□ 数据冲突/缺失已写入「待确认」
□ 用到的外部素材/模板许可证允许商用（见第 8.5 节）
```
